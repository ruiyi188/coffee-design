# ☕ Coffee Design — 品牌文案指南 (Copywriting Guide)

> 版本：v1.1.0 | 生效日期：2026-03-29

## 核心基调：温暖、专业、克制、有仪式感

我们传达的不是功能，而是**时间、感官与风土的连接**。每一句话都应该像一杯精心萃取的手冲咖啡：纯粹、无杂质、余韵悠长。

## 1. 写作原则

### 🔴 避免：空泛口号与广告腔
- ❌ “最好的咖啡，给你最棒的体验！”
- ❌ “超值特惠，限时抢购！”
- ❌ “采用顶级咖啡豆，口感绝佳。”

### 🟢 推荐：具体、感官可感知、克制陈述
- ✅ “这是时间的礼物。从高海拔庄园到你的杯中，跨越一场漫长的风土之旅。”
- ✅ “让呼吸慢下来，注水，等待，感受焦糖与柑橘果香慢慢释放。”
- ✅ “中度烘焙，保留了危地马拉特有的巧克力尾韵。”

## 2. 结构规范（页面级）

每个内容页面必须包含以下基本结构，保持信息层级清晰：

1. **清晰的主标题 (H1)**：少于 8 个字，概括核心主题（如“时间的尺度”、“冲煮的仪式”）。
2. **一段价值说明 (2-4句话)**：补充主标题，描述能带给用户的具体感受或核心价值。
3. **一致的结构段落**：每段不超过 4 行，适度留白。
4. **明确的行动引导 (CTA)**：按钮文案必须是动宾结构，明确预期目标。
   - ❌ “点击这里” / “更多”
   - ✅ “开启冲煮” / “探索风土” / “回到首页”

## 3. 词汇表 (Glossary)

统一全站的专业术语，避免中英混杂或同义词混用：

| 推荐用词 | 避免用词 | 场景说明 |
|--------|---------|---------|
| 冲煮 (Brewing) | 泡咖啡 / 冲咖啡 / 煮咖啡 | 指代手冲或精细咖啡制作过程 |
| 风味 (Flavor / Notes) | 味道 / 口感 | 描述咖啡具体的香气与味觉特征（如柑橘、花香） |
| 风土 (Terroir) | 产地 / 种植地 | 强调地理气候对咖啡豆的综合影响时使用 |
| 咖啡豆 (Coffee Beans) | 豆子 / 咖啡粉 | 除非特指已研磨状态，否则统一称“咖啡豆” |
| 闷蒸 (Blooming) | 泡水 / 润湿 | 手冲咖啡第一阶段的标准术语 |
| 萃取 (Extraction) | 过滤 / 溢出 | 咖啡液从咖啡粉中溶解出的过程 |
